## Changes

- Automatic update discovery at startup and every six hours, plus Check for updates.
- Explicit Update now and Later actions with release notes and download progress.
- Rust-side installation reservation that blocks updates during tracking, pending records, or unfinished session recovery.
- Signature verification and signed-version binding through the official Tauri updater.
- Protected candidate build and static Hetzner publication plumbing, with staging before production and manifest promotion last.

## Worker upgrade

Existing versions 0.1.0 and 0.1.1 cannot update themselves.
After the production installer is approved, stop tracking, wait for zero queued records, quit, and install the new version manually once as the same Windows user.
Do not uninstall or delete application data as an upgrade shortcut.
Keep organization security controls enabled.
Updater signatures are not Windows publisher signatures and do not remove SmartScreen warnings.
